# 🚀 GAIA 인프라 자동화 (Terraform)

이 리포지토리는 [GAIA](https://github.com/capston2025) 프로젝트의 안정적이고 확장 가능한 **AWS 클라우드 인프라 구축**을 위한 **IaC (Infrastructure as Code)** 리포지토리입니다. AWS 리소스를 **Terraform**을 사용하여 선언적으로 정의하고 관리합니다.

## 🌟 프로젝트 목표

Terraform을 활용하여 GAIA 개발 환경 및 운영 환경에 필요한 핵심 AWS 인프라를 **자동화, 반복 가능, 버전 관리 가능**하게 프로비저닝하는 것을 목표로 합니다.

  * **배포 속도 향상:** 인프라 변경 사항을 빠르고 일관되게 적용합니다.
  * **운영 일관성 확보:** 환경 간의 구성 차이(Drift)를 최소화합니다.
  * **비용 효율성:** 불필요한 리소스 생성을 방지하고 투명한 리소스 관리를 실현합니다.

-----

## 🛠️ 핵심 학습 및 적용 리소스

현재 이 리포지토리의 Terraform 코드는 다음과 같은 AWS 핵심 서비스를 중점적으로 다룹니다.

| 서비스 | 역할 및 학습 목표 |
| :--- | :--- |
| **VPC** | **네트워크 격리 및 설계**의 기본. GAIA 인프라를 위한 안전하고 사용자 정의된 가상 네트워크 환경 구축. (서브넷, 라우팅 테이블, 게이트웨이 포함) |
| **EC2** | **핵심 애플리케이션 서버** 프로비저닝. GAIA 서비스 구동을 위한 컴퓨팅 리소스 정의. (보안 그룹, 키 페어, AMI 학습) |
| **S3** | **정적 파일 호스팅 및 백업 저장소**로 활용. 고가용성 객체 스토리지 관리 및 정책 학습. |
| **IAM** | **보안 및 접근 제어** 확립. 리소스에 대한 **최소 권한 원칙**을 적용하는 역할(Role) 및 사용자(User) 정책 정의. |

## 🏗️ 리포지토리 구조

```
.
├── modules/
│   ├── vpc/             # VPC, Subnet 등 네트워크 모듈
│   ├── ec2/             # EC2 인스턴스 및 관련 보안 그룹 모듈
│   ├── s3/              # S3 버킷 및 정책 모듈
│   └── iam/             # IAM 사용자, 역할, 정책 모듈
├── envs/
│   ├── dev/             # 개발 환경(Dev) 설정을 위한 파일
│   └── prod/            # 운영 환경(Prod) 설정을 위한 파일 (TBD)
├── main.tf              # 루트 모듈 (주요 리소스 통합)
├── variables.tf         # 입력 변수 정의
└── versions.tf          # Terraform 및 Provider 버전 정의
```

## ⚙️ 시작하기 (Getting Started)

### 1\. 전제 조건

  * **Terraform CLI** (`vX.XX.X` 이상 권장)
  * **AWS CLI** 및 자격 증명 설정 완료
  * **Git**

### 2\. 인프라 배포 단계

1.  **리포지토리 클론:**

    ```bash
    git clone [리포지토리 URL]
    cd [리포지토리 이름]
    ```

2.  **모듈 초기화:**

    ```bash
    terraform init
    ```

3.  **계획 확인 (Plan):**
    실제 적용 전에 변경될 사항을 확인합니다.

    ```bash
    terraform plan -var-file="envs/dev/dev.tfvars"
    ```

4.  **인프라 적용 (Apply):**
    계획된 변경 사항을 AWS에 적용합니다.

    ```bash
    terraform apply -var-file="envs/dev/dev.tfvars"
    ```

### 3\. 인프라 제거 (Destroy)

> **⚠️ 주의:** 모든 프로비저닝된 리소스가 삭제됩니다.

```bash
terraform destroy -var-file="envs/dev/dev.tfvars"
```
